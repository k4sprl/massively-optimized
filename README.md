This pack aims to optimize Minecraft in terms of performance, privacy and usability.
## 🚀 Key Features
*   **Massive FPS Boosts:** Uses industry-standard performance mods like Sodium to ensure high framerates, reduced micro-stutters, and smooth gameplay.
*   **Privacy First:** Protects your data and chat using mods like No Telemetry, No Chat Reports, and No Chat Restrictions.
*   **Zero Clutter:** No unnecessary gameplay changes or bloated menus. Just Minecraft, but better.
*   **Version Specific Builds:** 
    *   **1.14+ (Fabric):** The ultimate modern optimization experience.
    *   **1.8.9 (Forge):** A lightweight version specifically tailored for older servers, PvP, and Bedwars.

### 🛠️ Core Mods Include:
**Performance**

*   Sodium
*   Lithium

**Privacy**

*   No Chat Reports
*   No Chat Restrictions
*   No Telemetry

**Looks**

*   Iris
*   Resourcify
